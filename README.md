# منصة الأجندة الشبابية السودانية

نموذج عرض بصفحة واحدة، متجاوب مع الهاتف وسطح المكتب، ومهيأ للنشر على GitHub Pages.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub واجعل الفرع الرئيسي `main`.
2. من إعدادات المستودع افتح **Pages**.
3. اختر **GitHub Actions** كمصدر النشر.
4. مع كل رفع جديد إلى `main` سيُبنى الموقع ويُنشر تلقائيًا.

أمر التحقق من النسخة النهائية:

```bash
npm run build
```
